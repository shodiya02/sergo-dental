# 0001 — Выбор цвета обивки убран из конфигуратора, шагом 1 стал выбор исполнения

- Статус: принято
- Дата: 2026-09-08

## Контекст

Конфигуратор открывался экраном «Шаг 1 из 2 — Выберите цвет обивки»: 19 цветов
в двух палитрах (стандартная и Memory Foam). Цвет **не влиял на стоимость** —
он лишь печатался строкой в КП и показывался в серой плашке над комплектацией.

При этом первый реальный выбор клиента — [исполнение](../../CONTEXT.md#исполнение-variant)
(Continental / Continental Hybrid / International / …) — не был представлен в
интерфейсе вообще. С главной страницы карточка линейки вела сразу на исполнение
Continental, без объяснения, что их несколько. Разница между исполнениями —
до ~930 $ и разный перечень комплектации, то есть ровно тот выбор, ради которого
конфигуратор и существует.

Побочный эффект: в КП название печаталось с отброшенным суффиксом исполнения
(«S380 TRC» для всех трёх), и единственным, что отличало два КП друг от друга,
была строка цвета. Убрав цвет, мы бы сделали разные КП неотличимыми.

## Решение

1. Экран выбора цвета удаляется со всех 26 страниц конфигуратора вместе с
   палитрами, кнопками «Перейти к комплектации» / «Пропустить» и строкой цвета в КП.
   Цвет обивки согласуется менеджером при оформлении заказа.
2. Роль «шага 1» переходит к выбору исполнения. Он живёт не внутри страницы
   конфигуратора, а на **новой странице линейки** (`s380-trc.html` и пять
   аналогичных), которая перечисляет реальные исполнения этой линейки и ведёт
   на существующие страницы конфигураторов.
3. Серая плашка над комплектацией сохраняется, но показывает исполнение;
   кнопка «Изменить» возвращает на страницу линейки.
4. КП печатает полное название исполнения.

## Альтернативы

- **Оставить цвет шагом 2 из 3.** Отвергнуто: выбор, не влияющий ни на цену,
  ни на комплектацию, стоял между клиентом и конфигуратором.
- **Показывать выбор исполнения внутри страницы конфигуратора**, а не отдельной
  страницей. Отвергнуто: тогда каждая из 26 страниц должна знать про своих
  «соседей» по линейке; отдельная страница линейки даёт то же самое, но с
  собственным URL, которым можно поделиться.
- **Одинаковые три исполнения для всех линеек** (как в исходной постановке).
  Отвергнуто: набор исполнений у каждой линейки свой — у S320TR их пять,
  у S200 есть Orthodontic, у S300 нет Hybrid.

## Последствия

- Страницы исполнений открываются сразу на комплектации — прямые ссылки и
  закладки продолжают работать.
- Данные существующих исполнений не трогаются; `data/s380-trc-continental.js`
  и его страница остаются как есть.
- Если цвет обивки понадобится вернуть, палитры придётся восстанавливать из
  истории git (см. `assets/configurator.js`, объект `COLORS`).
- Каталог остаётся плоским списком всех 26 исполнений: это поверхность для тех,
  кто уже знает, что берёт.
